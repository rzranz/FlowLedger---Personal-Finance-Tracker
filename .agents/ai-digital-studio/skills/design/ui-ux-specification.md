# Skill: UI/UX Specification

## 1. Purpose
Produce implementable screen, flow, and interaction specifications.

## 2. Used By
- `roles/ui-ux-designer.md`

## 3. Required Inputs
- Requirements
- Creative direction
- Content inventory
- Target devices

## 4. Procedure
1. Build sitemap and navigation model.
2. Map primary user flows.
3. Specify each screen: layout, components, content, states (empty, loading, error, success).
4. Define responsive breakpoints and behavior.
5. Define interactions, motion intent, and accessibility requirements.
6. Trace each requirement to a screen or component.

## 5. Outputs
- Sitemap
- Flow specs
- Screen and component specs
- Responsive and interaction rules

## 6. Quality Criteria
- All requirements are traced.
- States are specified.
- Breakpoint behavior is explicit.
- Keyboard and focus behavior is defined.

## 7. Boundaries
- Do not fabricate evidence, sources, results, or file paths.
- Stay within the task's scope and permissions.
- Report limitations and unverified items.
