# Skill: Visual Identity

## 1. Purpose
Define a coherent visual identity system from creative direction.

## 2. Used By
- `roles/creative-director.md`
- `roles/brand-designer.md`

## 3. Required Inputs
- Creative brief
- Audience and positioning
- Existing brand constraints

## 4. Procedure
1. Restate direction and constraints.
2. Define color palette with values and usage roles.
3. Select typography with hierarchy and fallbacks.
4. Define logo or mark requirements and clear-space rules.
5. Define imagery, iconography, and layout principles.
6. Check contrast and consistency; document guidelines.

## 5. Outputs
- Brand specification
- Usage guidelines
- Asset list with formats

## 6. Quality Criteria
- Values are specific (hex, font names, sizes).
- Contrast is checked for text uses.
- Guidelines are usable without the designer present.

- Do not fabricate evidence, sources, results, or file paths.
