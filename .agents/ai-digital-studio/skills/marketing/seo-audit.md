# Skill: SEO Audit

## 1. Purpose
Assess search visibility fundamentals and prioritize fixes.

## 2. Used By
- `roles/marketing-growth.md`

## 3. Required Inputs
- Site URL or source files
- Target topics or region
- Access to analytics, if available

## 4. Procedure
1. Review technical basics: crawlability, indexability, speed, mobile.
2. Review on-page: titles, headings, meta, internal links, structured data.
3. Review content gaps against target topics.
4. Note local SEO factors when relevant.
5. Prioritize fixes by impact and effort.
6. State what could not be checked.

## 5. Outputs
- Audit report
- Prioritized fix list
- Open data needs

## 6. Quality Criteria
- Findings are evidence-based.
- No promised rankings.
- Impact labeled as estimate.

## 7. Boundaries
- Do not fabricate evidence, sources, results, or file paths.
- Stay within the task's scope and permissions.
- Report limitations and unverified items.
