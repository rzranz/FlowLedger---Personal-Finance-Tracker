# Skill: Frontend Development

## 1. Purpose
Implement UI to specification with maintainable, accessible code.

## 2. Used By
- `roles/software-engineer.md`

## 3. Required Inputs
- Design and component specs
- Tech stack decision
- Assets

## 4. Procedure
1. Set up structure per the chosen stack.
2. Build reusable components.
3. Implement responsive layouts and states.
4. Ensure semantic markup, keyboard access, and focus states.
5. Run available lint, build, and tests; record outcomes.
6. Write setup notes.

## 5. Outputs
- Source code
- Build or run instructions
- Check results and limitations

## 6. Quality Criteria
- Layout works at agreed viewports without horizontal overflow.
- Interactive elements are keyboard accessible.
- No known console errors in the tested flow.

## 7. Boundaries
- Do not fabricate evidence, sources, results, or file paths.
- Stay within the task's scope and permissions.
- Report limitations and unverified items.
