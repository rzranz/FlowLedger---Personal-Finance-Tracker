# Skill: Interactive Website

## 1. Purpose
Plan and build a content-led website with purposeful motion and interaction.

## 2. Used By
- `roles/ui-ux-designer.md`
- `roles/software-engineer.md`

## 3. Required Inputs
- Approved design and content
- Performance and device targets
- Allowed libraries

## 4. Procedure
1. Define page structure and interaction inventory.
2. Choose motion only where it serves comprehension or feel.
3. Implement with semantic HTML and progressive enhancement.
4. Respect reduced-motion preferences.
5. Check performance, responsiveness, and accessibility.
6. Document run and build steps.

## 5. Outputs
- Working site source
- Interaction notes
- Setup instructions
- Known limitations

## 6. Quality Criteria
- Content is usable without motion.
- `prefers-reduced-motion` is honored.
- No unapproved third-party dependencies.
- Verification actually performed is recorded.

## 7. Boundaries
- Do not fabricate evidence, sources, results, or file paths.
- Stay within the task's scope and permissions.
- Report limitations and unverified items.
