# Skill: PRD Generation

## 1. Purpose
Convert a goal into a structured product requirements document.

## 2. Used By
- `roles/product-strategist.md`

## 3. Required Inputs
- Business goal
- Audience
- Constraints
- Research findings, if any

## 4. Procedure
1. State the problem and goal.
2. Define audience and key scenarios.
3. List requirements with priority (must/should/could).
4. Write acceptance criteria per requirement.
5. Define out-of-scope items and success metrics.
6. List assumptions and open questions.

## 5. Outputs
- PRD document
- Prioritized requirement list
- Acceptance criteria

## 6. Quality Criteria
- Requirements are testable.
- Scope boundaries are explicit.
- No invented budgets, deadlines, or client demands.

## 7. Boundaries
- Do not fabricate evidence, sources, results, or file paths.
- Stay within the task's scope and permissions.
- Report limitations and unverified items.
